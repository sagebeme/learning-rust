The story

Can Amina move to cargo?

One question, eight weeks

Amina Wanjiru is a ramp agent at the Nairobi station. She wants to move to cargo handling. Can she start? What's missing? Who needs to be told, and when?

Every project answers a piece of that question, with fake data from TWA's world: staff, stations, licences and expiry dates. By week 8 you run a small TWA yourself: a server that answers HR's transfer question, and a 06:00 job that reminds Amina a week before her certificate expires.

Weeks 5–7 run the rules engine you build in week 4. If yours isn't finished, they use a ready-made one, so you're never blocked.

Flight plan

    Each week

    Three kinds of work

    On TWA you'll review more code than you write, and you'll explain your decisions to people who don't write code at all. The course practises all three.

    1

    Build

    Small numbered tasks, each starting as todo!(), with a strict checker: the tests, and clippy with warnings as errors.

    2

    Review

    From 0x03, a pull request with problems planted in it. Write the review you'd leave, then compare it with the answer key.

    3

    Explain

    A short note for an HR or training manager about one decision from the week. No jargon: practice for client meetings.

    From your terminal

    Let Cargo tick the boxes

    Run cargo xtask progress in the course folder. It runs every project's tests and clippy, without changing your code, and prints where each task stands. It also saves progress.json.

    Serve the course folder and this board updates by itself:

    Then open http://localhost:8000/site/. On the hosted site, use Load progress.json instead. Progress stays in your browser either way.
